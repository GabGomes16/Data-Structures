# Data Structures – UFMG (2024/2)

This repository contains the practical assignments and implementations developed during the **Data Structures** course at UFMG.

The focus of the course was algorithm analysis, classical data structures, and efficient problem solving.

---

## 📚 Course Topics

### 🔎 Algorithm Analysis
- Introduction to complexity analysis  
- Asymptotic complexity (Big-O notation)  
- Analysis techniques and recursion  
- Master Theorem  

### 🔄 Sorting Algorithms
- Bubble Sort  
- Insertion Sort  
- Selection Sort  
- Merge Sort  
- Shellsort  
- Quicksort  
- Counting Sort  
- Bucket Sort  
- Radix Sort  
- Heapsort  
- External Sorting  

### 🧱 Fundamental Data Structures
- Arrays  
- Linked Lists  
- Stacks  
- Queues  
- Heaps and Priority Queues  
- Sparse Matrices  

### 🌳 Trees
- Tree traversal  
- AVL Trees  
- B-Trees  

### 🔗 Graphs
- Graphs and Digraphs  
- Connectivity and Minimum Spanning Trees  
- Disjoint Set Union (DSU)  

### ⚡ Advanced Topics
- Hashing and primary memory search  
- Locality of reference  

---

## 💻 Language

Most implementations were developed in **C**, focusing on performance and memory management.
